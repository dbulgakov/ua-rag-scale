## Sources and attribution

- **Questions and reference answers:** UA-SQuAD (`FIdo-AI/ua-squad`, https://huggingface.co/datasets/FIdo-AI/ua-squad). This is a Ukrainian translation of SQuAD (Rajpurkar et al., 2016), distributed under CC BY-SA 4.0. Translated UA-SQuAD contexts are not included and were never used as evidence.
- **Evidence passages:** Ukrainian Wikipedia, © Wikipedia contributors, CC BY-SA 4.0 (https://uk.wikipedia.org).
  - Snapshot: `wikimedia/wikipedia`, configuration `20231101.uk`, revision `b04c8d1ceb2f5cd4588862100d08de323dccfbaa` (https://huggingface.co/datasets/wikimedia/wikipedia/tree/main/20231101.uk).
  - A passage id `native-uk:<page_id>:<start>:<end>` is a character range of that page's text in the snapshot. It was chunked into 384 tokens with 32-token overlap by `raglab.data.chunking.chunk_sentences`.
- **Judge outputs:** generated by the listed LLMs through OpenRouter (model and provider are stored in every row), shared for reproducibility of the evidence judgement.

Changes made: questions were aligned automatically to native Ukrainian Wikipedia passages, then each question–passage pair was judged by LLMs. No manual annotation was done. This adaptation is shared under the same license.

## Files

- `benchmark-v2/questions-primary.jsonl` — main set. A pair is accepted by a 2-of-3 vote of model families (Qwen3-235B, Gemini 2.5 Flash, GPT-4.1-mini). Split: test 739 / tune (`dev`) 148 / train 735; article splits are fixed.
  - Fields: `id`, `language`, `question`, `answers`, `original_answers`, `split`, `article_id`, `component_id`, `group_keys`, `gold_groups` (alternative passage ids per evidence group), `evidence` (answer span inside the passage), `metadata`.
- `benchmark-v2/questions-{qwen,flash,mini,prefilter}.jsonl` — robustness sets: a single judge, or all candidates before judging.
- `benchmark-v2/manifest.json` — counts, vote rule and fingerprints.
- `judges/raw-responses.jsonl.gz` — one row per judged pair.
  - Fields: `judge`, `candidate_id`, `question_id`, `document_id`, `accepted`, `status`, `raw_response`, `provider`, `model`, `response_id`, `finish_reason`, `prompt_tokens`, `completion_tokens`.
  - Qwen, Gemini 2.5 Flash and GPT-4.1-mini judged all 11,058 pairs. GPT-4.1 and Gemini 2.5 Flash-Lite judged only the 297-pair pilot.
- `judges/summary.json` — row counts by judge.

- `pool/uk.parquet`, `pool/en.parquet` — the fixed 1M passage pools: passage `id` in pool order and the growth `tier` (0 evidence, 1 hard tier, 2 the rest). `raglab data` rebuilds the pools from the raw sources and checks them against these lists.
- `pool/uk-benchmark-articles.json` — the 82 candidate articles of the Ukrainian benchmark, always included in the pool.
- `pool/en-question-splits.parquet` — the HotpotQA question ids used as test, tune (`dev`) and train. HotpotQA is distributed under CC BY-SA 4.0.

The benchmark and judge files were produced by the original run of the project; the pipeline in this repository consumes them as inputs.
